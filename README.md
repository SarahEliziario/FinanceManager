# 💰 Finance Manager

Welcome to the Finance Manager repository!

This project was developed with **Python** to practice back-end programming and improve my problem-solving skills. It is a simple application that helps users manage their personal finances in an organized way.

The program allows users to register and manage financial information through an easy-to-use menu, making it a great project for learning Python fundamentals.

## Features

* 💵 Add income and expenses
* 📋 View financial records
* ✏️ Edit existing records
* 🗑️ Delete records
* 📊 Track your finances in a simple way

## Purpose

The main goal of this project was to strengthen my Python knowledge by working with programming logic, data organization, and user interaction. It is part of my learning journey toward becoming a Back-End Developer.

Thank you for visiting my project! 🚀
